JUST - Creating a New App Password

The supplied JUST guide describes these steps:

1. Sign in to Office 365 at outlook.office.com.
2. Open Settings.
3. Scroll down to Office 365.
4. Navigate to Security & Privacy.
5. Expand Additional security verification.
6. Select Create and manage app passwords.
7. Click Create.
8. Choose a name for the app password.
9. Click Next.
10. Copy the generated app password and save it securely.
11. Use it when setting up a mail application.

The source guide states that this app password is used for mail
applications except Microsoft Outlook 2016.

Security note:
Never share an app password with anyone or include an actual
generated password in project training data.
