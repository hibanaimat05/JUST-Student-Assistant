# JUST Student Assistant

## Project Overview
JUST Student Assistant is an AI-powered conversational assistant designed to help students at Jordan University of Science and Technology (JUST).

The system aims to provide accessible information about university services, academic resources, and student-related questions.

## Project Objectives
- Answer students' questions about university services.
- Provide accessible and organized university information.
- Support academic and administrative inquiries.
- Improve response quality using Large Language Models (LLMs).

## Technologies
- Python
- Natural Language Processing (NLP)
- Large Language Models (LLMs)
- Continued Pre-Training (CPT)
- Supervised Fine-Tuning (SFT)

## Project Pipeline
1. Data Collection
2. Data Preparation
3. Continued Pre-Training (CPT)
4. Supervised Fine-Tuning (SFT)
5. Model Evaluation
6. Results Analysis

## Repository Structure
The repository contains training scripts, source code, configuration files, datasets, testing resources, and model evaluation results.
